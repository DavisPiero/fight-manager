# Fight Manager

Run an MMA management agency in your browser. Sign prospects, build them up in the gym, work the corner on fight night, and sell them to rival agencies when their value peaks, or keep them and chase the belt.

```bash
npm install
npm run dev
```

Then open http://localhost:5173. Add `?mute` to the URL for silence. `npm test` runs a headless smoke test.

Unofficial fan game, not affiliated with the UFC. Fighter records as of November 2026; skills are the game's own estimates. Fighter photos come from Wikimedia Commons under free licences; credits are in-game under Office › Credits and in `src/data/photos.json`.
